# UI/UX Portfolio Landing Page

A modern and clean portfolio landing page created using HTML and CSS.  
This project is designed for practicing frontend development and improving UI/UX design skills.

## 🚀 Features

- Modern landing page design
- Responsive layout
- Navigation header
- Hero section
- Services section
- Portfolio showcase
- Interactive buttons and hover effects
- Font Awesome icons integration

## 🛠️ Technologies Used

- HTML5
- CSS3
- Font Awesome

## 📂 Project Structure

```bash
├── index.html
├── style.css
├── images/
```
